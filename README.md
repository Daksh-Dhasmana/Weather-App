# 🌤️ Weather Web

A clean, responsive, and modern weather web application built as part of The Odin Project curriculum. The app dynamically fetches real-time weather data using an external API to provide users with up-to-date conditions, accurate temperatures, and localized weather descriptions.

![Project Preview](https://github.com/user-attachments/assets/03a7b03f-010c-4ad2-97f7-9a8d7325d842)

---

## 🚀 Features

*   **Real-time Data Fetching:** Seamlessly integrates with a weather API to retrieve live data for any searched location.
*   **Dynamic UI Elements:** Automatically displays appropriate weather emojis based on current climate conditions (sunny, rainy, cloudy, etc.).
*   **Frosted Glass Aesthetic:** Features a modern glassmorphism UI designed to look beautiful over organic, natural backgrounds.
*   **Fully Modular Codebase:** Built using Webpack to bundle assets, handle modular JavaScript modules, and optimize build scripts.

---

## 🛠️ Built With

*   **HTML5 & CSS3** (Custom Flexbox layout & Glassmorphism effects)
*   **Vanilla JavaScript** (ES6+ Modules, Async/Await, Fetch API)
*   **Webpack** (Asset management, development server, and production bundling)
*   **Weather API** (Data retrieval)
